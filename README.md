# Leterizza

Site de educação digital desenvolvido como projeto de estudo no Bootcamp Orion. O objetivo é praticar o gitflow.

## Funcionalidades

- Conteúdo introdutório sobre educação digital.
- Botão para visualizar dicas.
- Quiz com uma pergunta e duas alternativas como feature a ser colocada. 
- Explicação para respostas corretas e incorretas.
- Layout adaptado para computadores e celulares.

## Como executar

Clone ou baixe o repositório e abra o arquivo `index.html` no navegador. Não é necessário instalar dependências.

## Estrutura

- `index.html`: estrutura e conteúdo da página.
- `styles.css`: estilos e adaptação de tela.
- `index.js`: funcionamento das dicas e do quiz.

## Organização das branches

- `feature/`: desenvolvimento de novas funcionalidades.
- `dev`: integração das funcionalidades revisadas.
- `stage`: conferência da versão antes da entrega.
- `prod`: versão aprovada do projeto.

As funcionalidades são propostas por pull requests para `dev`. Após a revisão, seguem para `stage` e depois para `prod`.

## Sobre o projeto

Projeto fictício criado para fins educacionais.
